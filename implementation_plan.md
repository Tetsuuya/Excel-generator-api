# Implementation Plan: Workbook Quality-Evaluation & Cognitive Planning Framework Upgrade

Upgrade the **AI Excel Generator** from a basic "code-that-doesn't-crash" generator into a mature **Multi-Stage Cognitive Planning & Post-Execution Quality Evaluation System**.

---

## 1. Architectural Vision & Core Pillars

Instead of relying on a single monolithic prompt that blindly trusts any `.xlsx` file generated by Python, the upgraded system introduces **three cognitive layers**:

```
[ User Natural Language Prompt ]
              │
              ▼  (STAGE 1: COGNITIVE PLANNING)
   [ Intent & Schema Planner (core/planner.py) ]
   - Classifies Domain (Financial, Medical/Operations, Executive, Sales, etc.)
   - Constructs JSON Workbook Schema (Sheets, Columns, Formula Dependency Graph, KPI Specs, Chart Targets)
              │
              ▼  (STAGE 2: PRECISION CODE GENERATION)
   [ Target Python openpyxl Generator ]
   - Employs Domain-Specific Design Tokens & Reusable Helper Functions
   - Enforces AST Security Validation (core/sanitizer.py)
   - Runs in Subprocess Sandbox (core/executor.py)
              │
              ▼  (STAGE 3: POST-EXECUTION WORKBOOK LINTER & AUDITOR)
   [ In-Memory Workbook Quality Auditor (core/validator.py) ]
   ├── 🔍 Formula Integrity Linter: Checks for formula errors, range drifts, circular refs
   ├── ⚖️ Financial & Data Reconciler: Validates KPI cards match table sums & aggregations
   ├── 🎨 Format & Type Consistency: Verifies date/currency/percentage formats across columns
   ├── 📐 Layout & Space Auditor: Checks column widths, chart dimensions, and empty space
   └── 📊 Quality Scoring Engine: Computes a comprehensive 0–100 Quality Index
              │
              ▼  (Quality Score < 90 or Critical Issues Detected?)
     [ Quality-Driven Self-Correction Feedback Loop ] ──↺ (Up to 2 healing iterations)
              │
              ▼  (Quality Score >= 90)
   [ Production-Grade, Executive .xlsx Binary Stream + Quality Report ]
```

## 2. Proposed Module Structure & Changes

### [NEW] `core/planner.py` (Stage 1: Cognitive Planner)
* **`analyze_intent_and_plan(prompt: str, client: OpenAI) -> WorkbookPlan`**:
  * Extracts domain theme (e.g. *Corporate Financial, Healthcare Operations, Tech SaaS Metrics*).
  * Synthesizes a structured JSON Workbook Schema:
    * Worksheets to create.
    * Columns per worksheet with expected data types and number format rules.
    * Exact KPI card metrics and mathematical formula definitions.
    * Cross-sheet formula linkages (e.g., `Dashboard!C5 = SUM('Raw Data'!P10:P1009)`).
    * Charts to build with precise x-axis categories and y-axis data series.

### [NEW] `core/validator.py` (Stage 3: Post-Execution Quality Linter)
* **`WorkbookValidator`**:
  * Loads the generated `.xlsx` bytes directly into `openpyxl.load_workbook(data_only=False)`.
  * **Rule 1: Formula Error & Syntax Audit**:
    * Checks all cell formula strings for malformed syntax, dangling commas, or invalid tokens.
    * Flags suspicious range references (e.g., `SUM(A10:A50)` when the table has 1,000 rows).
  * **Rule 2: Number Format & Type Consistency**:
    * Ensures numeric/currency columns don't have raw unformatted numbers.
    * Verifies date columns adhere to proper date formatting tokens.
  * **Rule 3: KPI & Header Alignment**:
    * Verifies that KPI cards are populated with valid values (not empty or raw code strings).
  * **Rule 4: Layout & Gridlines Enforcement**:
    * Checks that `showGridLines` is enabled on all views.
    * Verifies column dimensions are not default width (9.0) if content exceeds length.
  * **Rule 5: Chart Reference Audit**:
    * Inspects embedded `_charts` to verify `data_ref` and `cats_ref` point to existing sheets and valid non-empty cell boundaries.
  * **Calculates a composite Quality Score (0–100)**:
    * Returns a structured `ValidationResult` containing:
      * `is_valid: bool`
      * `quality_score: float`
      * `issues: List[str]` (Categorized by CRITICAL, WARNING, SUGGESTION)
      * `metrics: Dict[str, Any]` (Sheet count, cell count, formula count, chart count)

### [MODIFY] `services/excel_service.py` (Orchestration & Self-Correction)
* Integrates `core/planner.py` and `core/validator.py`.
* Upgrades `generate_excel()` workflow:
  1. Generate Code (leveraging the blueprint).
  2. AST check & Sandbox execution.
  3. Run `WorkbookValidator.audit_workbook(excel_bytes)`.
  4. If validation score is `< 85` or has critical errors, feeds the exact linter issue list into `QUALITY_HEALING_PROMPT` to refine the code.
  5. Returns both the verified `.xlsx` binary and the detailed `quality_audit` metadata in API response headers.

### [MODIFY] `core/prompts.py`
* Adds `QUALITY_HEALING_PROMPT_TEMPLATE` focusing on fixing semantic errors, formula discrepancies, and layout flaws.
* Adds Domain-Adaptive Design Tokens (Corporate Slate, Financial Emerald, Executive Navy, Modern SaaS).

### [MODIFY] `app.py`
* Adds `X-Workbook-Quality-Score` and `X-Quality-Issues-Count` headers to the `/api/generate-excel` endpoint.
* Exposes `POST /api/audit-workbook` endpoint to allow users/systems to audit any existing `.xlsx` file against the quality rules.

### [MODIFY] `ARCHITECTURE.md`
* Documents the upgraded Cognitive Planning and Quality Evaluation architecture.
